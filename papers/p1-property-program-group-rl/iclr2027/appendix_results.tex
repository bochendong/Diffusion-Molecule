\subsection{Reproducibility boundary}
\label{sec:appendix-reproducibility}

P18 uses one cached base model, one tokenizer, and one LoRA adapter. Its frozen
adapter SHA256 is
\texttt{7b3e1736bac49b7b2e35eceeed11fde199e0403a948e4dae08fd4fb9b89a0827}.
The expanded editing comparison uses byte-identical prompts and matching seeds
for P17 and P18, with a task-stratified paired condition bootstrap (10,000
replicates, seed 1919). The de novo extension generates only ranks 9--40 after
verifying that ranks 1--8 are byte-identical to the earlier locked run. No
training, threshold change, or benchmark-driven tuning occurs after freezing
either checkpoint.
